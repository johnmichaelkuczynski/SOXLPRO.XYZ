What was measured

A fresh Python process on an isolated workspace port, with Playwright Chromium already open before timing begins. Existing provider disk caches were retained in both runs. The after run starts the real supervised background worker. The initial saved-data page is timed; full Streamlit chart readiness is a separate later stage. These are not production-idle measurements and do not include platform container allocation.

Startup audit and changes

Previously the listener waited for Streamlit imports. The first UI request then imported analytics, scientific and AI libraries, downloaded full SOXL history, fetched quotes and intraday bars, computed signal/snapshot values, and eagerly rendered premium tabs with options-chain downloads, volatility surface fitting and dislocation calculations.

The lightweight listener now opens first and serves the last valid PostgreSQL snapshot and signals. Streamlit and the market worker run in supervised child processes. The worker refreshes history and overlays every five minutes, quotes/intraday feed/snapshot every minute, and publishes versioned results atomically. Advisory locking prevents duplicate workers. Failures retain the last valid values with source/timestamp/error status. Reads never create tables or call market providers. Daily and short-term signal definitions are unchanged.

Premium tabs are selection-aware and heavy tab modules import only when selected. Explicit user-initiated backtests, research, strategy generation and checkout verification are not automatic startup jobs and retain their existing behavior. Authentication, entitlement checks, visitor counters, report file reading and browser-side chart rendering remain separate from market recomputation.

Limitations

The two-second result requires an existing saved record and a responsive database. An empty or unavailable database produces an explicit pending/unavailable page, never fabricated values. On a new production database the worker must publish its first successful snapshot before last-known results exist. The full interactive UI initializes after the saved page. A Reserved VM avoids idle container allocation, but restarts still initialize processes. Republish is required before these changes affect the live app.

Reproduction

Run scripts/cold_start_probe.cjs on an isolated instance with the backend port free. Do not run beside another gateway sharing backend port 8501. Raw measurements are stored alongside this report. Unit tests cover DB budgets, atomic writes, retained state, provider deadlines and signal preservation.
